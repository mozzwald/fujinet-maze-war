# 08-01 — Reclaim obsolete Atari presentation space

## Model and handoff

Use **`gpt-5.6-terra` with high reasoning**. Bounded deletion still needs reachability, fixed-address, and shared-buffer analysis.
Follow [08-MODELS.md](08-MODELS.md) for escalation, testing-based commit
approval, and handoff rules.

After required acceptance, recommend **08-02: `gpt-5.6-sol`, high
reasoning** for room ownership and poll-loop isolation. Include this in the
user-facing closing summary and saved summary, then pause for the user's model
switch. If a test/approval gate is pending, say the recommendation is conditional;
do not mark the step complete or begin the next step.

## Goal

Remove unreachable title/game-over implementation and establish a measured
memory budget before new Atari state is added.

## Changes

1. Prove with exhaustive caller searches that `GAMEOVR`, `TITLDISP`, and the
   old `TITLES` payload are unreachable on the net-only path.
2. Delete `GAMEOVR..ENDGOBK`. Retain shared primitives such as `EVAPRTE`; move
   any accidentally nested live helper before deletion if caller analysis finds
   one.
3. Remove only the unused title display-list/data bytes at `$8000`. Preserve
   `HOSTDISP`, `GAME`, `MAZEDAT`, and all screen buffers.
4. Reserve the reclaimed `$8000` data area for new title, room-menu, and result
   strings/layout tables. Do not fill it with placeholders in this plan.
5. Extend `memory_layout_smoke.sh` to print and enforce code/data high-water
   marks, zero-page end, and minimum headroom thresholds. Keep all existing
   ANTIC and overlap checks.
6. Record before/after symbol addresses and XEX size in the summary.
7. Audit `WINPLYR` and every reference to deleted labels, including tests that
   currently require `TITLDISP`. Preserve live charset/animation tables. Measure
   a forced baseline build first: old symbol addresses are inventory hints,
   not proof of currently available space. Fixed `.org` holes do not become
   usable storage automatically.
8. Produce a lifetime/address table for persistent round results, menu rows,
   AppKey scratch, and the 189-byte Lobby record. Scattered 60-byte packet
   buffers are not a contiguous 189-byte allocation. Reserve an explicit
   contiguous overlay only if both mainline and VBI/IRQ ownership permit it;
   otherwise select a bounded streaming parser before approving the budget.

## Verification

- Forced Atari rebuild and full smoke suite.
- Boot through MCP-managed Atari800/FujiNet-PC and reach normal play.
- Exercise death/respawn to prove deleting local `GAMEOVR` did not remove live
  vaporization primitives.
- Capture a screen and memory-layout output.

## Acceptance

Normal gameplay is byte-protocol compatible, the unreachable presentation is
gone, and measured headroom is available for later plans.
