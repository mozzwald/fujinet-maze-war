# 08-04 — Nonblocking Atari round-end presentation

## Model and handoff

Use **`gpt-5.6-sol` with high reasoning**. 6502 effects share VBI, staging, sound, and display state with ongoing networking.
Follow [08-MODELS.md](08-MODELS.md) for escalation, testing-based commit
approval, and handoff rules.

After required acceptance, recommend **08-05: `gpt-5.6-sol`, high
reasoning** for leave, grace, and shared session teardown. Include this in the
user-facing closing summary and saved summary, then pause for the user's model
switch. If a test/approval gate is pending, say the recommendation is conditional;
do not mark the step complete or begin the next step.

## Goal

Replace the removed local game-over routine with a server-triggered state
machine that keeps VBI and networking alive.

## Atari states

Add non-zero-page state and frame deadlines for:

`PLAYING -> LOSER_EVAP -> WINNER_DANCE -> WINNER_EVAP -> FADE -> RESULTS -> WAIT_ROUND_START`.

Mainline continues `NET_POLL`, reliable ACKs, and neutral heartbeat service in
every state. Separate receiving/staging from gameplay commits: VBI must not
apply a late respawn or movement update over a result effect. Follow the epoch
and readiness contract in `08-PROTOCOL.md`.

## Presentation changes

1. On the first accepted MATCH_END, freeze names, scores, masks, winner, round
   ID, and kill limit. Suppress movement/fire TX.
2. Start existing mushroom-cloud/vaporization primitives for every active
   loser without calling `VBIOFF` or blocking.
3. Animate the winner for roughly one second using existing directional frames
   and frame timers; do not create new large graphics.
4. Vaporize the winner with the existing effect.
5. Fade palette shadow registers by small VBI-timed steps with DLI disabled.
6. Switch `DLIST` to `HOSTDISP`, clear `HOSTSCR`, and draw final text from the
   frozen result data. Reuse the reclaimed old-title constant area for strings
   and layout tables.
7. Distinguish human-only, human-over-Zombies, and Zombie-win wording. Render
   slot-qualified fallback names so duplicate Zombies remain clear.
8. Remain on results until the matching ROUND_START gate is complete; local
   timers never restart the round.
9. Add a simpler synchronized results presentation to SDL so cross-client
   round state remains visible during testing.
10. Skip unavailable/dead actors and let a completed server ROUND_START gate
    interrupt any unfinished effect. A late join shows results directly. Audit
    `EVAPRTE`/completion callers for gameplay respawn side effects before reuse;
    presentation effects must not create server requests or advance scores.
11. Restore palette shadows, charset, display list, PMG/HUD missile markers,
    sound ownership, and gameplay staging gates explicitly on restart/leave.
    `HOSTDISP` needs the correct text charset. Preserve the POKEY channel 3/4
    NetStream guard; no fade/effect may write those registers. Use PAL/NTSC-aware
    presentation timers without retuning accepted gameplay movement cadence.

## Verification

  repeated rounds.
- Verify `NMIEN=$40`, VBI progresses, DLI remains disabled, NetStream remains
  active, and watchdog counters reset from frozen snapshots.
- Memory-layout suite and visual captures for every presentation state.
