# 08-08 — Asynchronous QA Lobby publisher

## Model and handoff

Use **`gpt-5.6-terra` with medium reasoning**. The publisher is isolated behind copied metadata, bounded work, and fake-endpoint tests.
Follow [08-MODELS.md](08-MODELS.md) for escalation, testing-based commit
approval, and handoff rules.

After required acceptance, recommend **08-09: `gpt-5.6-sol`, high
reasoning** for bounded binary parsing and Atari menu memory. Include this in the
user-facing closing summary and saved summary, then pause for the user's model
switch. If a test/approval gate is pending, say the recommendation is conditional;
do not mark the step complete or begin the next step.

## Architecture

Keep HTTPS outside `server/main.c`'s simulation/poll loop. Prefer a small
publisher module with a worker thread and bounded queue, or a companion helper
process fed occupancy snapshots. The simulation may enqueue metadata without
waiting for DNS, TLS, HTTP, or retries.

This step executes after 08-07 for a serial user/model handoff; its server
prerequisites are the room and occupancy lifecycle from 08-02 through 08-05.
Pick one publisher architecture at implementation start and document it. Pass
copied immutable room metadata to the publisher; a worker never owns or mutates
simulation-room state. Bound queue size and shutdown time, and prevent a stale
queued refresh from republishing a room after its shutdown removal. Signal
handlers only request shutdown; they perform no HTTPS or thread joins.

## Changes

1. Add explicit `--lobby-enabled`; default off. Add QA/production base URL,
   game/appkey, client URL, public host, room names, refresh interval, and
   request timeout configuration.
2. Register every room independently with distinct `tcp://host:port`, human-only
   `curplayers`, and `maxplayers=4`.
3. Coalesce occupancy changes, refresh before Lobby expiry, bound retry/backoff,
   and expose failures in logs without stopping gameplay.
4. On SIGINT/SIGTERM, stop accepting new work, attempt bounded removal/offline
   publication for every room, then close sockets. Never hang shutdown on the
   Lobby.
5. Prevent LAN/test invocations from publishing through both default-off
   behavior and test assertions.
6. Pin the tested QA request/response contract in `doc/lobby.md`; do not assume
   production identity or an unregistered appkey.

## Verification

- Local fake endpoint contract tests for register/update/refresh/shutdown,
  malformed replies, timeouts, and server errors.
- Prove a deliberately stalled publisher does not delay 10 Hz room ticks.
- QA write test only after endpoint/appkey coordination.
- Verify restart upserts rather than duplicates and every room is removed or
  marked offline according to the live QA contract.
